# Gestión de Jugadores

## Intro
Aplicación para la gestión de jugadores de un equipo de fútbol (más adelante ampliaré el rango de deportes, hasta el punto de tener un tracking deportivo más generalizado)

## Tecnologías
- React
- Django Rest Framework
- PostgresSQL
- Docker
